
# AWS Web App Task

This is a simple task manager web application deployed on AWS.

### 🔹 Frontend:
- HTML, CSS, JavaScript
- Hosted on AWS S3 (Static Website Hosting)

### 🔹 Backend:
- AWS Lambda (Node.js)
- Connected via API Gateway (GET & POST methods)

### 🔹 Live Hosted Website:
http://hrutik-aws-webapp.s3-website.eu-north-1.amazonaws.com

### 🔹 API Gateway Endpoint:
https://d1fbv3e2sc.execute-api.eu-north-1.amazonaws.com/prod

### 🔹 Folder Structure:
- /lambda/index.mjs (Lambda handler)
- /frontend/index.html
- /frontend/style.css
